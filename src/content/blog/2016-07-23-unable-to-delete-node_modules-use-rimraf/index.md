If you have done node application development in windows machine often you might have faced issue where the node\_modules directory which you created would not delete when you try to delete.

Node’s approach to package management is often criticized because of its endless nested modules folders on windows.

To solve this issue you can use the rimraf create by [Nikola Breznjak](https://twitter.com/HitmanHR) by following below steps

Install rimraf

> npm install -g rimraf

Delete node\_modules

> rimraf node\_modules

Note: If you faced any issues try running the command again and it should work

Hope this helps someone like it did for me!!
